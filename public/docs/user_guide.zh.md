# MicsBook 用户指南

MicsBook 是一个运行在浏览器中的私人电子书库，支持手机、平板和电脑。登录后，即可随时随地阅读、收听和整理您的图书 —— 安装为应用后，即使在离线状态下也可以使用。

## 登录

- 使用管理员为您创建的邮箱账户登录，或者当图书馆启用了 **Google** 登录时使用它。
- 全新图书馆中创建的第一个账户会自动成为**管理员**。

## 查找图书

顶部导航提供了多种浏览方式：

- **图书** —— 全部藏书，按最新在前排序。使用视图按钮在卡片网格和紧凑列表之间切换，并可按需排序。
- **作者** 和 **系列** —— 按名称浏览，每个页面列出对应的图书。
- **搜索** —— 按书名、作者或系列搜索。
- **随机** —— 从您的书库中随机挑选一本。

每本书的页面都会显示封面、简介、作者、系列和出版日期，并提供**阅读**和**下载**按钮。

## 阅读

- **EPUB** 图书在自带阅读器中打开，包含目录、页码和位置栏。
- **PDF** 图书在自带的 PDF 阅读器中打开。
- 阅读位置会被记住，您可以关闭图书，稍后继续从上次的位置阅读。

阅读时，**阅读工具** 让您可以：

- **收藏书签** 标记当前阅读位置。
- 为任意段落写一条**笔记**，并引用原文。
- 随时跳回您的书签和笔记。

书签和笔记仅对您的账户可见。

## 收听（朗读）

按 EPUB 阅读器底部的圆形播放按钮，即可让图书朗读出来。使用旁边的选项按钮可以：

- 开启**播放时间后停止**并选择分钟数 —— 朗读会在累计播放达到该时长后自动停止。
- 开启**阅读时保持屏幕常亮**，在朗读高亮段落时屏幕不会熄灭。

在支持的浏览器中，切换应用或锁定屏幕后播放仍会继续；可使用通知栏或锁屏上的媒体控件来暂停、继续或停止。

## 我的书库

**我的书库** 是您的私人空间，包含所有个性化内容：

- **最近阅读** —— 您最近读过的图书。
- **书单** —— 创建命名书单（例如“夏日书单”），并可从任意图书页面添加图书到其中。
- **标签** —— 按自己的习惯为图书添加标签，并可按标签浏览。

我的书库中的内容仅对您可见。

## 分享图书

在任意图书页面，**分享此书** 区域（当您的账户被允许创建分享链接时）提供：

- **分享…** 按钮，使用设备自带的分享面板。
- **WhatsApp**、**Telegram**、**Facebook** 和 **X** 的快捷链接，会打开预先填好的分享消息。
- **复制链接** 按钮，将图书地址复制到剪贴板。

收到链接的人如果拥有该图书馆的访问权限，就可以打开这本书。

## 下载

使用任意图书页面上的**下载**按钮，即可将文件以原始 EPUB 或 PDF 格式保存到您的设备。

## 离线阅读

联网登录后，打开书籍详情页并点击**离线保存**。请保持页面打开，直到显示**可离线阅读**。
此操作会保存完整的 EPUB 或 PDF，并准备阅读器。仅打开过书籍并不代表已离线保存。

在书库导航或阅读器菜单中打开**离线书籍**，即可阅读下载、查看占用、移除下载或调整默认
500 MB 的书籍存储上限。达到上限时不会自动删除其他书籍；请移除下载或提高上限。
阅读器文件另外使用少量空间，供所有离线书籍共用。

下载保存在此设备上此网站的浏览器存储中，与**下载**按钮保存的文件分开。正常更新应用
会保留它们。清除网站数据、退出登录或切换账户时会移除下载；空间不足时浏览器也可能
清理数据。**请求持久存储**可以请求保留下载，但是否允许由浏览器决定。移除下载不会
影响服务器上的原书，也不会清除已保存的本地阅读位置。

朗读始终优先尝试在线语音，包括阅读离线保存的书籍时。服务失败或超时后，会使用已安装
的英语或中文本地语音；如无可用语音，请在设备设置中安装离线语音。稍后或重新联网时会
重试在线朗读，不会永久保存朗读音频。PDF 支持离线阅读，朗读仍为 EPUB 阅读器的功能。

书签、笔记、翻译、词典查询和浏览未保存的书籍需要联网。本次功能不包含离线书签或跨设备
阅读进度同步。

## 安装应用

MicsBook 是一个渐进式网页应用（PWA），可以像原生应用一样安装：

- **Android / Chrome**：选择*添加到主屏幕*，或在地址栏点击安装图标。
- **iOS / Safari**：点击*分享*按钮，然后选择*添加到主屏幕*。

安装后，应用会全屏打开、启动更快；明确点击**离线保存**的书籍无需网络也可阅读。

## 角色

图书馆采用基于角色的权限控制：

- **读者** —— 浏览、阅读、下载，并使用个人功能。
- **经理** —— 拥有读者的全部权限，外加**管理 → 书库**中的书库管理功能（上传图书、重新扫描、恢复删除）。
- **管理员** —— 拥有完全控制权，包括**管理**中的用户和设置。

管理员可以在**管理 → 用户**中管理账户：修改角色和启用状态、查看每位用户的上次登录时间和上次 IP 地址、查看他们阅读过的图书，以及按需重置密码。

## 需要帮助？

如果您无法登录、图书无法打开，或者缺少某个功能，请联系图书馆管理员。
